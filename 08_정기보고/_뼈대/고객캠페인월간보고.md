# 고객캠페인 월간보고 뼈대
- 주기: 월간 / 보고 회의: 다음 달 월간 운영회의
- 작성 팀: 운영기획팀
- 출처 회차: 2026년 7월 보고 (`04_월간보고/7월_고객캠페인_월간보고_완성본.pptx`)
- 교육용 가상 자료 · 실제 SK브로드밴드 문서 아님

## 지표 정의
| 지표 | 정의·계산식 | 단위 | 비고 |
|---|---|---|---|
| 상담 | 고객과 실제 상담한 건수 | 건 | 원본 열: 상담 건수 |
| 유효신청 | 신청(접수건) − 취소 | 건 | |
| 집행액 | 부가세 제외 비용 | 원 | 원본 열: 사용금액(원). 천원·만원·VAT 포함 파일은 환산 |
| 전환율 | 유효신청 합계 ÷ 상담 합계 | % (소수 1자리) | 지역 비율 단순평균 금지 |
| 건당비용 | 집행액 ÷ 유효신청 | 원 (반올림) | |
| 예산집행률 | 집행액 ÷ 승인예산 | % | 승인예산 자료가 있을 때만 |
| 목표 달성률 | 유효신청 ÷ 유효신청 목표 | % | 목표 자료가 있을 때만 |

집계 기준: 보고기간 내 마감(확정) 기록만 · 중복은 기록번호+수정차수로 판단 · 잠정·오류·확인필요 기록은 제외하고 따로 표시

## 섹션 순서
1. 결론 한 줄 + 지난달과 달라진 점 3가지
2. 결과 요약 — 신청 실적 / 비용 / 다음 달 검토 (3칸)
3. 보고 범위 — 기간, 마감 기준, 지역(수도권·충청·호남·영남·강원·제주), 활동(온라인안내·현장상담·기존고객안내)
4. 지표 정의 — 상담 / 유효신청 / 집행액 / 건당비용
5. 예산·목표 대비 — 자료 있을 때만, 없으면 "자료 없음 — 비교 제외"
6. 지역별 성과 표 — 지역 | 집행액(원) | 유효신청(건) | 전환율 | 건당비용(원) + 합계
7. 지난달 대비 증감 — 유효신청·집행액·전환율·건당비용
8. 다음 달 운영 검토 — A 성과 확인 / B 비용 개선 / C 확인 후 반영
9. 출처·집계 기준

## 문장 패턴
- 신청 실적: "유효신청 {n}건을 기록했습니다. 상담 {m}건 대비 전환율은 {r}%입니다."
- 비용: "{금액}원을 집행했습니다. 유효신청 1건당 비용은 {c}원입니다."
- 운영 의견: "{전환율 최고 지역}의 성과를 참고하고, {건당비용 최고 지역}의 건당비용과 채널 구성을 점검합니다."

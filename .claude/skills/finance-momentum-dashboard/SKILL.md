# 재무 개선 모멘텀 대시보드

회사별 매출·영업이익·순이익·부채·자본을 **표준 재무표** 하나로 모은 뒤, 스크립트 한 번으로 점수 계산과 대시보드를 만든다.
계산·화면은 스크립트가 맡고, Claude는 **입력 정리와 결과 확인**에 집중한다. 템플릿 HTML을 새로 쓰지 않는다.

수강생에게는 CLAUDE.md의 말투(부드러운 존댓말, 결론 먼저, 진행 상황 알림)를 따른다.

## 경로

- 스킬 폴더: 이 파일이 있는 폴더 (`.claude/skills/finance-momentum-dashboard`, 아래 `$SK`)
- Python: 프로젝트 `.venv`의 실행 파일 (macOS `.venv/bin/python`, Windows `.venv\Scripts\python.exe`). 필요한 기능 묶음: `requests`, `python-dotenv`, `openpyxl`, `pandas`
- 작업용 중간 파일은 스크래치패드나 결과 폴더의 `_work/`에 둔다. 결과 HTML은 사용자가 지정한 곳, 없으면 `06_SKB재무정보/`

## 1단계 — 입력 경로 고르기

| 사용자가 준 것 | 할 일 |
|---|---|
| 재무 실적 파일 (xlsx/csv) | **A. 파일 경로**로 간다 |
| 회사 이름 목록만 ("SK 계열사", "통신 3사") | **B. API 경로**로 간다 |
| 둘 다 | 파일을 우선하고, 빠진 회사만 API로 채운다. 두 출처를 섞었다고 `--note`로 적는다 |

### A. 실적 파일 → 표준 재무표

1. 파일을 모두 열거하고 시트·열 이름·단위·연도 범위를 확인한다. 한글 파일명 문제는 `korean-safe-windows` 스킬을 따른다.
2. [references/data-format.md](references/data-format.md)의 매핑 표로 열을 맞춰 **표준 재무표 CSV**를 만든다 (pandas 사용, 원본은 수정하지 않음).
3. 단위가 파일마다 다르면 하나로 맞추고, 바꾼 값을 원본 합계와 대조한다.
4. 매핑이 애매한 열(예: "수익"이 매출인지 영업수익인지)은 추측하지 말고 사용자에게 한 번 묻는다.
5. 재무 항목이 없는 실적(캠페인 건수 등)이면 이 스킬을 억지로 쓰지 말고 어떤 지표로 볼지 확인한다.

### B. 회사 이름 → API로 받기

1. API 키 확인: `$PY check_api_key.py`가 있으면 실행, 없으면 `DATA_GO_KR_API_KEY` 존재만 확인. 키 값은 화면에 출력하지 않는다.
2. 회사 목록 파일을 만든다. 한 줄에 `회사명,사업군`. 그룹 전체를 달라고 하면 **상장사 + 주요 비상장사**로 시작하고, 공식 계열사 전체 목록이 아니라는 점을 결과에 밝힌다.
   - DART 이름은 영문 약칭(`SK하이닉스`)과 한글 표기(`에스케이브로드밴드`)가 섞여 있다. 못 찾으면 다른 표기로 다시 찾는다.
3. 법인등록번호 찾기:
   ```
   $PY $SK/scripts/dart_lookup.py --names-file names.txt --out companies.csv
   ```
   `match`가 `exact`가 아닌 회사는 `candidates` 열을 보고 맞는 회사를 골라 `crno`를 고친다. 이름이 비슷한 다른 회사(예: `SK에너지판매`)를 넣지 않는다.
4. 재무 데이터 받기 (회사당 몇 초):
   ```
   $PY $SK/scripts/fetch_fin_api.py --companies companies.csv --years 2023-2025 --out fin_long.csv
   ```
   0건인 회사는 제외 목록에 넣는다. "등록되지 않은 서비스키"가 나오면 data.go.kr에서 「금융위원회_기업 재무정보」 활용신청 상태를 확인하도록 안내한다.

## 2단계 — 대시보드 만들기

```
$PY $SK/scripts/build_dashboard.py --input fin_long.csv --unit 원 \
  --title "SK 계열사 재무 개선 모멘텀" \
  --source "공공데이터포털 「금융위원회_기업 재무정보」 API(요약재무제표)" \
  --note "회사 범위: 상장사와 주요 비상장 계열사를 골랐어요. 공식 계열사 전체 목록이 아니에요." \
  --excluded "SK텔링크:API 데이터 없음;SK플래닛:API 데이터 없음" \
  --out 06_SKB재무정보/SK계열사_재무모멘텀_대시보드.html
```

- 파일 경로(A)에서는 `--source`에 원본 파일 이름을, `--unit`에 실제 단위를 넣는다.
- 결과: HTML 1개 + 같은 이름의 `.data.json`(계산 결과). 콘솔에 회사별 점수·분포·**확인 필요** 목록이 나온다.
- 회사가 1곳이어도 동작한다(순위 1행 + 상세).

## 3단계 — 확인 (생략 금지)

1. 콘솔의 **확인 필요** 항목을 모두 읽는다. 부채비율 불일치·빈 값·연도 부족은 원인을 확인하고 사용자에게 알린다.
2. 브라우저 창에서 HTML을 열어 KPI·순위·상세·사업군 차트·표가 보이는지 본다. 스크린샷 1~2장이면 충분하다.
3. 점수 분포 합계 = 최근 연도가 있는 회사 수인지 맞춘다.
4. 튀는 숫자(매출 ±100% 이상, 이익률 ±100%p 이상)는 합병·분할·지주회사 회계 같은 구조 변화일 수 있다고 알린다. 원인을 지어내지 않는다.

## 점수 규칙 (스크립트에 구현됨 — 바꾸려면 사용자에게 먼저 확인)

전년 대비 좋아진 항목마다 1점 (5점 만점): 매출 증가 · 영업이익 증가 · 영업이익률 상승 · 순이익 증가 · 부채비율 하락.
4~5점 ▲개선 / 2~3점 ▶혼조 / 0~1점 ▼악화. 적자 폭 축소도 '증가'. 자본 0 이하는 '자본잠식'으로 표시하고 부채비율 점수 없음.
회사별로 연결·별도 중 연도가 많은 기준을 쓰고, 같으면 `--prefer`(기본 연결).

## 보고 형식

끝나면 채팅에 다음을 짧게 적는다.
- 결과 파일 링크
- 대상 회사 수, 원본 건수, 제외된 회사와 이유
- 개선·혼조·악화 회사 수와 대표 회사 몇 곳
- 데이터의 한계(회사 범위, 미공시 연도, 구조 변화 가능성)

## 하지 말 것

- 템플릿을 새로 그리거나 색을 바꾸지 않는다 (SKB 색은 `assets/template.html`에 들어 있음).
- 확인되지 않은 법인등록번호, 단위, 수치를 추측해서 넣지 않는다.
- API 키나 키가 들어간 URL을 채팅·파일·커밋에 남기지 않는다.
- 사용자가 회사 범위를 정하지 않았는데 수백 곳을 한꺼번에 조회하지 않는다. 범위를 먼저 알린다.

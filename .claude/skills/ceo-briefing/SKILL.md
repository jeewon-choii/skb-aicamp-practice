# CEO 보고본 만들기

원문을 **줄이는 것**이 아니라, CEO가 **10초 안에 결론을, 1분 안에 근거를** 알 수 있게 다시 배열하는 작업이다.
원문에 없는 숫자·판단은 만들지 않는다. 바꿔 쓴 곳은 담당자 확인을 받는다.

수강생에게는 CLAUDE.md의 말투(부드러운 존댓말, 결론 먼저, 진행 상황 알림)를 따른다.

## 경로

- 스킬 폴더: 이 파일이 있는 폴더 (아래 `$SK`)
- Python: 프로젝트 `.venv` (macOS `.venv/bin/python`, Windows `.venv\Scripts\python.exe`). 필요한 기능 묶음: `pillow` (도식), 원문 형식에 따라 `python-docx`·`python-pptx`·`pdfplumber`
- 결과 폴더: 사용자가 정한 곳, 없으면 `07_CEO보고/YYYY-MM-DD_주제/`
- 한글 파일명 문제는 `korean-safe-windows` 스킬을 따른다

## 1단계 — 원문 받기

| 받은 것 | 할 일 |
|---|---|
| 채팅에 붙여넣은 글 | 그대로 원문으로 쓴다. 결과 폴더에 `원문.txt`로 저장해 둔다 |
| 캡처 이미지 | Read로 이미지를 보고 글·숫자를 옮긴다. 흐릿해서 못 읽은 숫자는 `[판독 불가]`로 남기고 추측하지 않는다 |
| 내보낸 파일 (docx·pdf·pptx·html) | 기능 묶음으로 텍스트·표를 뽑는다. 원본은 수정하지 않는다 |
| 컨플루언스 링크만 | 이 스킬은 컨플루언스에 직접 연결하지 않는다. 페이지 내용을 복사해 붙여넣거나 Word/PDF로 내보내 달라고 안내한다 |

원문 담당자(작성자·팀)가 원문에 있으면 기록한다. 없으면 메신저 문구에 `[담당자]` 자리만 둔다.

## 2단계 — 핵심 뽑기 (작업 메모)

결과 폴더에 `_work/핵심메모.md`를 만들고 원문을 네 칸으로 나눈다.

1. **결론·요청**: 원문이 결국 말하려는 것, CEO에게 바라는 것(승인·인지·의사결정)
2. **숫자**: 값, 단위, 기간, 비교 기준, **원문 위치**(쪽·슬라이드·문단)
3. **근거·경과**: 결론을 받치는 사실
4. **리스크·미정 사항**

원문에 결론이 명시되지 않았으면, 원문 근거로 결론 후보를 쓰고 `[확인]`을 붙인다.

## 3단계 — CEO 보고본 쓰기

[assets/briefing-template.md](assets/briefing-template.md)의 틀을 그대로 쓴다. 순서는 바꾸지 않는다.

1. 한 줄 결론
2. 핵심 3가지 (3개를 넘기지 않는다. 더 있으면 세부 내용으로 내린다)
3. 도식 1개
4. 숫자 표
5. CEO 결정·확인 필요 사항 (없으면 "보고(인지) 사항"이라고 적는다)
6. 세부 내용 (원문 순서대로, 짧게)
7. 출처·확인 상태

문장 규칙은 [references/writing-rules.md](references/writing-rules.md)를 따른다. 쓰기 전에 한 번 읽는다.

## 4단계 — 도식 만들기

[references/diagram-patterns.md](references/diagram-patterns.md)에서 내용에 맞는 도식 종류를 고른다. 원문 내용이 그 모양일 때만 쓴다.

1. 도식 내용을 JSON으로 쓴다 (`_work/diagram.json`, 형식은 diagram-patterns.md)
2. PNG를 만든다:
   ```
   $PY $SK/scripts/make_diagram.py --spec _work/diagram.json --out 도식.png
   ```
3. Read로 PNG를 열어 글자가 잘리거나 겹치지 않는지 직접 본다. 문제가 있으면 문구를 줄여 다시 만든다.
4. 보고본에는 도식과 **같은 내용의 짧은 표나 목록**을 함께 둔다 (이미지가 안 보여도 읽히도록).

## 5단계 — 확인 표시와 메신저 요청문

- 원문과 표현이 달라진 숫자·결론·용어에 `[확인]`을 붙인다. 계산해서 새로 만든 값(증감률 등)도 계산식과 함께 `[확인]`.
- `메신저_확인요청.txt`에 담당자별 요청문을 쓴다. **한 사람당 5줄 이내**:

  ```
  [담당자]님, CEO 보고용으로 「주제」 내용을 정리했어요.
  아래 2가지만 맞는지 봐주실 수 있을까요?
  1) "원문 표현" → "바꾼 표현"
  2) 증감률 12.3%(=값A÷값B−1)로 계산했어요
  [마감] 전까지 회신 부탁드려요. 감사합니다!
  ```
  - 확인할 항목이 3개를 넘으면 중요한 3개만 넣고 "나머지는 페이지에 표시해 뒀어요"라고 쓴다.
  - 마감일을 사용자가 말하지 않았으면 `[마감]` 자리로 남긴다.

## 6단계 — 저장과 붙여넣기

결과 폴더에 다음을 저장한다.

| 파일 | 용도 |
|---|---|
| `CEO보고본.html` | 브라우저로 열어 전체 선택(⌘A/Ctrl+A) → 복사 → 컨플루언스 편집기에 붙여넣기. 제목·표·굵은 글씨가 유지된다 |
| `CEO보고본.md` | 같은 내용의 마크다운 (다른 곳에 옮길 때) |
| `도식.png` | 컨플루언스 편집기에 따로 끌어다 놓기 (HTML 안의 이미지는 붙여넣기로 올라가지 않을 수 있다) |
| `메신저_확인요청.txt` | 메신저에 복사 |

HTML은 컨플루언스가 받아들이는 단순 태그만 쓴다: `h2·h3·p·ul·ol·li·table·tr·th·td·strong·em·img`. 색은 `[확인]` 표시(주황 `#F47725`)와 결론 강조(빨강 `#EA002C`)에만 쓰고 인라인 스타일로 넣는다. 글꼴은 지정하지 않는다(컨플루언스 기본 글꼴 사용).

## 7단계 — 마무리 확인 (보고 전에 반드시)

- [ ] 원문 숫자를 보고본 숫자와 하나씩 대조했다 (개수: 원문 n개 / 보고본 m개 / 일치 k개)
- [ ] 원문에 없는 숫자가 있다면 모두 계산식과 `[확인]`이 붙어 있다
- [ ] 한 줄 결론이 맨 위에 있고 40자 안팎이다
- [ ] 핵심은 3개 이하다
- [ ] 도식 PNG를 직접 열어 봤다
- [ ] 메신저 문구가 담당자당 5줄 이내다

사용자에게는 결과 폴더, 대조 결과(숫자 개수), `[확인]` 항목 수, 붙여넣는 방법을 짧게 알린다.

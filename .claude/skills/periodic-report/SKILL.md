# 정기 보고서 만들기

지난 보고서를 **양식**으로, 새 데이터를 **내용**으로 쓴다. 매번 새로 디자인하지 않는다.
보고서 시리즈마다 **뼈대 파일**을 한 번 만들어 두고, 다음 회차부터는 뼈대만 읽고 바로 쓴다.

수강생에게는 CLAUDE.md의 말투(부드러운 존댓말, 결론 먼저, 진행 상황 알림)를 따른다.
문장 규칙은 [../ceo-briefing/references/writing-rules.md](../ceo-briefing/references/writing-rules.md)를 함께 따른다.

## 경로

- 스킬 폴더: 이 파일이 있는 폴더 (아래 `$SK`)
- Python: 프로젝트 `.venv` (macOS `.venv/bin/python`, Windows `.venv\Scripts\python.exe`). 기능 묶음: `openpyxl`·`pandas`, 원문 형식에 따라 `python-pptx`·`python-docx`·`pdfplumber`
- 뼈대 보관: `08_정기보고/_뼈대/<보고서이름>.md`
- 결과 폴더: 사용자가 정한 곳, 없으면 `08_정기보고/<기간>_<보고서이름>/` (예: `2026-08_고객캠페인월간보고`)
- 한글 파일명 문제는 `korean-safe-windows` 스킬을 따른다

## 1단계 — 뼈대 확인

1. `08_정기보고/_뼈대/`에 이 보고서의 뼈대가 있으면 읽고 2단계로 간다.
2. 없으면 지난 보고서를 읽고 [references/skeleton-guide.md](references/skeleton-guide.md)대로 뼈대를 만든다.
   - 지난 보고서: 컨플루언스 글 붙여넣기, 또는 내보낸 파일(pptx·docx·pdf·html)
   - 뼈대에는 **섹션 순서, 지표 정의·단위·계산식, 표 열 구성, 문장 패턴, 지난 회차 숫자**를 적는다.
3. 뼈대를 사용자에게 5줄 이내로 요약해 보여주고, 바꿀 곳이 있는지 한 번 묻는다. (다음 회차부터는 묻지 않는다)

## 2단계 — 새 기간 데이터 모으기

1. 데이터 파일을 모두 열거하고 시트·열·단위·기간을 확인한다. 원본은 수정하지 않는다.
2. 뼈대의 **지표 정의대로** 집계한다. 단위(원/천원/만원, VAT 포함 여부)와 기간이 다르면 맞추고, 바꾼 내용을 기록한다.
3. 집계 결과를 `_work/이번기간.csv`로, 지난 회차 숫자를 `_work/지난기간.csv`로 저장한다 (형식은 아래 3단계).
4. 원본 건수·합계와 집계 합계가 맞는지 확인한다. 미확정·확인필요 기록이 있으면 포함 여부를 따로 적는다.
5. 지난 보고서에 있던 지표인데 이번 데이터가 없으면 (예: 목표·예산) **만들지 않는다.** "자료 없음 — 비교 제외"로 표시하고 마지막에 사용자에게 알린다.

## 3단계 — 전기 대비 비교표

```
$PY $SK/scripts/compare_periods.py \
  --prev _work/지난기간.csv --curr _work/이번기간.csv --key 지역 \
  --ratio "전환율=유효신청/상담:%" --ratio "건당비용=집행액/유효신청:원" \
  --prev-label 7월 --curr-label 8월 --out-dir _work
```

- CSV: 첫 열이 구분(지역·채널 등), 나머지 열은 숫자. `합계` 행이 있으면 그 값을 쓰고, 없으면 더한다.
- 비율 지표는 **분자 합계 ÷ 분모 합계**로 계산한다(단순 평균 아님). 지난 회차에 분모가 없으면 비율 열을 CSV에 직접 넣는다. 그때는 원문 값을 그대로 쓴다.
- 결과: `비교표.md`, `비교표.html`, `변화요약.json`(증감이 큰 순서).

## 4단계 — 이번 보고서 쓰기

뼈대의 섹션 순서를 그대로 따른다. 맨 위에는 항상 다음 두 가지를 둔다.

1. **한 줄 결론**: 이번 기간의 가장 중요한 변화 1개 (예: `8월 유효신청 7,728건(+208건), 영남 건당비용 상승 점검 필요`)
2. **지난번과 달라진 점 3가지**: `변화요약.json`의 상위 항목 중 의미 있는 것. 숫자가 크게 변한 곳의 이유가 데이터에 없으면 "원인 확인 필요"로 쓴다. 이유를 지어내지 않는다.

본문은 지난 보고서의 문장 패턴을 숫자만 바꿔 쓰되, 반복되는 상투 문장보다 이번 기간의 사실을 우선한다.
도식이 필요하면 `../ceo-briefing/scripts/make_diagram.py`를 쓴다 (형식: [../ceo-briefing/references/diagram-patterns.md](../ceo-briefing/references/diagram-patterns.md)).

## 5단계 — 숫자 대조표

`_work/숫자대조.csv`에 보고서에 나온 숫자를 모두 적는다: `위치, 지표, 보고서 값, 원본 값, 원본 위치, 일치`.
- 원본에서 바로 가져온 값과 계산한 값을 구분한다 (계산은 계산식 표시).
- 불일치가 하나라도 있으면 보고서를 고치고 다시 대조한다.

## 6단계 — 저장과 안내

| 파일 | 용도 |
|---|---|
| `보고서.html` | 브라우저로 열어 전체 선택 → 복사 → 컨플루언스 편집기에 붙여넣기 |
| `보고서.md` | 같은 내용의 마크다운 |
| `도식.png` (있으면) | 컨플루언스에 따로 끌어다 놓기 |
| `_work/` | 집계 CSV, 비교표, 숫자 대조표 |

HTML 규칙은 ceo-briefing과 같다: 단순 태그만, 강조색은 SK Red `#EA002C`·Orange `#F47725` 인라인, 글꼴 지정 없음. 증감은 `▲ +n`/`▼ −n` 글자로 표시한다(색만으로 구분하지 않음).

CEO 보고용 요약본도 필요하면 `ceo-briefing` 스킬로 이어서 만든다.

## 7단계 — 마무리 (반드시)

- [ ] 원본 건수·합계와 보고서 합계가 같다 (보고에 원본 건수와 합계를 함께 적는다)
- [ ] 숫자대조.csv 불일치 0건
- [ ] 이번 데이터에 없는 지표를 만들지 않았다 ("자료 없음" 표시 확인)
- [ ] 뼈대 파일의 "지난 회차 숫자"를 이번 숫자로 갱신했다 (다음 회차 비교용)

사용자에게는 결과 폴더, 원본 건수·합계, 대조 결과, 자료가 없어 뺀 항목을 짧게 알린다.

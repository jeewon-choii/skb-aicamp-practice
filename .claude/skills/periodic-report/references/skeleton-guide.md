# 보고서 뼈대 만들기

뼈대 = 지난 보고서에서 **매번 같은 것**만 뽑은 설계도. 다음 회차는 뼈대 + 새 데이터만으로 쓴다.
파일 위치: `08_정기보고/_뼈대/<보고서이름>.md`

## 뽑는 법

1. 지난 보고서의 섹션(슬라이드·제목)을 순서대로 적는다.
2. 섹션마다 **고정 요소**와 **바뀌는 요소**를 나눈다.
   - 고정: 제목 패턴, 설명 문구, 표 열 구성, 지표 정의, 집계 기준
   - 바뀌는 것: 기간, 숫자, 운영 의견, 다음 달 검토 사항
3. 지표마다 정의·단위·계산식을 적는다. 원문에 정의가 없으면 `[정의 확인 필요]`.
4. 지난 회차 숫자를 표로 남긴다 (다음 회차의 "지난기간.csv"가 된다).

## 뼈대 파일 형식

```markdown
# <보고서이름> 뼈대
- 주기: 월간 / 보고 회의: 매월 첫째 주 월간 운영회의
- 작성 팀: 운영기획팀
- 출처 회차: 2026년 7월 보고 (04_월간보고/7월_..._완성본.pptx)

## 지표 정의
| 지표 | 정의·계산식 | 단위 | 비고 |
|---|---|---|---|
| 유효신청 | 신청 − 취소 | 건 | |
| 집행액 | 부가세 제외 비용 | 원 | |
| 전환율 | 유효신청 합계 ÷ 상담 합계 | % (소수 1자리) | 지역 비율 단순평균 금지 |
| 건당비용 | 집행액 ÷ 유효신청 | 원 (반올림) | |

## 섹션 순서
1. 표지 — "<월> 고객 캠페인 월간보고 / 지역별 실적과 비용으로 보는 <다음 달> 운영안"
2. 결과 요약 — 신청 실적 / 비용 / 다음 달 검토 (3칸)
3. 보고 범위 — 기간, 마감 기준, 지역·활동
...

## 문장 패턴
- 신청 실적: "유효신청 {n}건을 기록했습니다. 상담 {m}건 대비 전환율은 {r}%입니다."
- 운영 의견: "{최고 지역}의 성과를 참고하고, {점검 지역}의 {지표}를 점검합니다."

## 지난 회차 숫자 (<기간>)
| 지역 | 집행액 | 유효신청 | 상담 | 전환율 | 건당비용 |
|---|---|---|---|---|---|
| ... |

## 이번 데이터에 없을 수 있는 항목
- 승인예산·목표: 별도 자료. 없으면 "자료 없음 — 비교 제외"
```

## 주의
- 뼈대에 실제 회차의 운영 의견 문장을 그대로 넣지 않는다. 패턴(빈칸)만 남긴다.
- 사용자가 양식을 바꾸라고 하면 뼈대를 고치고, 고친 날짜를 맨 아래에 적는다.

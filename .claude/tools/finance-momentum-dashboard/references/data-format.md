# 표준 재무표 형식

`build_dashboard.py`는 이 형식 하나만 읽는다. 어떤 실적 파일이 오든 먼저 이 형식으로 바꾼다.
한 행 = 회사 1곳 × 연도 1개 × 기준 1개(연결/별도).

| 열 | 필수 | 설명 | 예 |
|---|---|---|---|
| company | ✅ | 회사 이름. 화면에 그대로 표시 | SK하이닉스 |
| year | ✅ | 사업연도 4자리 | 2025 |
| sales | ✅ | 매출액 (영업수익) | 971466000000000 |
| op_income | ✅ | 영업이익 (손실은 음수) | 472063000000000 |
| net_income | ✅ | 당기순이익 (손실은 음수) | 429479000000000 |
| total_debt | ✅ | 부채총계 | |
| total_equity | ✅ | 자본총계 | |
| total_assets | | 자산총계 | |
| basis | | `연결` 또는 `별도`. 없으면 `--prefer` 값 | 연결 |
| sector | | 사업군 (필터·묶음 차트에 쓰임). 없으면 `기타` | 반도체 |
| market, industry, crno | | 상세 화면 표시용 | 유가증권시장 |
| api_debt_ratio | | 원본에 있는 부채비율(%). 있으면 계산값과 대조 | 45.9 |

- 금액 단위는 파일 전체가 같아야 한다. `--unit 원|천원|백만원|억원`으로 알려준다.
- 숫자의 쉼표 `1,234`, 괄호 음수 `(1,234)`, `-`(빈 값)는 스크립트가 처리한다.
- 같은 회사·연도·기준이 두 번 나오면 스크립트가 멈춘다. 원본에서 어느 행이 맞는지 확인한다.
- 회사마다 최소 2개 연도가 있어야 점수를 낼 수 있다.

## 흔한 원본 열 이름 → 표준 열

| 원본에서 자주 보이는 이름 | 표준 열 |
|---|---|
| 회사명, 법인명, 계열사, 법인 | company |
| 연도, 사업연도, 결산연도, 회계연도, FY | year |
| 매출액, 매출, 영업수익, 수익(매출액) | sales |
| 영업이익, 영업이익(손실), 영업손익 | op_income |
| 당기순이익, 당기순이익(손실), 순이익, 당기순손익 | net_income |
| 부채총계, 총부채, 부채 | total_debt |
| 자본총계, 총자본, 자본 | total_equity |
| 자산총계, 총자산 | total_assets |
| 연결/별도, 재무제표 구분, 구분 | basis |

## 가로형(연도가 열) 원본

`회사 | 항목 | 2023 | 2024 | 2025` 처럼 연도가 열로 펼쳐진 표는 pandas `melt`로 세로형으로 바꾼 뒤
항목 이름을 위 표로 매핑하고 `pivot`한다. 바꾼 결과를 저장하기 전에 원본 합계와 행 수를 대조한다.

## 이 형식에 맞지 않는 실적

캠페인 실적(가입 건수·목표 달성률 등)처럼 재무제표 항목이 없는 파일은 이 스킬의 점수 규칙을 쓸 수 없다.
억지로 매핑하지 말고 사용자에게 어떤 지표로 모멘텀을 볼지 확인한다.

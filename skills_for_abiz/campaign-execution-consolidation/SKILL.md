# 캠페인 집행 취합본 → 통합본

담당자 여러 명이 보낸 집행 기록을 한 시트에 모은 취합본은 날짜·금액 형식이 섞이고, 수정 회신이 아래에 덧붙고, 임시 합계가 틀리는 일이 흔하다. 이 스킬은 그런 파일에서 **보고에 쓸 수 있는 확정 실적**을 뽑는다. 무엇을 왜 뺐는지, 숫자가 맞는지를 같은 파일 안에 남겨서 누가 봐도 따라 확인할 수 있게 한다.

## 결과물

원본 파일은 수정하지 않는다. 원본을 복사한 `<원본이름>_통합본.xlsx`를 만들고, 원래 시트는 그대로 둔 채 아래 시트 3개를 더한다.

| 시트 | 내용 |
|---|---|
| 확정실적 | 확정된 기록만 날짜순으로 담는다. 금액·건수는 숫자이고, 맨 아래 합계는 SUM 수식이다. 원본 행 번호와 검토 메모 열을 둔다. |
| 제외·수정내역 | ① 확정에서 뺀 원본 행과 그 구분·사유 ② 확정 행에서 바꾼 값(원본 값 → 바꾼 값, 이유) ③ 표기를 통일한 기준 |
| 검증 | 건수와 합계를 원본과 대조한 결과(수식이라 값을 고치면 다시 계산됨), 그리고 알아둘 점 |

## 진행 순서

### 1. 먼저 파악하고 사용자에게 알린다
바로 고치지 말고 파일부터 읽는다. 사용자가 "먼저 파악해줘"라고 할 수도 있고, 기준을 정하기 전에 결과부터 받으면 다시 해야 하기 때문이다.

- 시트 목록, 머리글 행, 데이터 행 수, 보고기간(보통 상단 안내 문구에 있음)을 확인한다.
- **메모·회신·안내 시트가 있으면 반드시 읽는다.** 담당자가 적은 집계 기준이 아래 기본 규칙보다 우선한다. 예: "수정차수가 높은 값 반영", "금액 누락 건은 0원으로 넣지 말 것", "잠정·기간 밖 자료 제외".
- 발견한 문제를 표로 짧게 보여준다. 예: 날짜 형식 혼재, 글자로 된 금액, 중간 머리글, 중복 ID, 틀린 임시 합계.
- 사용자가 정리를 원하면 다음 단계로 간다. 원본이 엑셀에서 열려 있어도 복사본으로 작업하므로 닫을 필요는 없다고 알려준다.

### 2. 스크립트로 통합본을 만든다

```bash
python scripts/build_consolidated.py "<취합본.xlsx>"
# 선택: --out "<저장 경로>"  --period 2026-08-01:2026-08-31  --sheet "<데이터 시트명>"
```

- 필요한 것: Python 3.8 이상과 openpyxl(엑셀 기능 묶음). 없으면 `pip install openpyxl`.
- 보고기간은 파일 상단 문구에서 자동으로 찾는다. 못 찾으면 사용자에게 기간을 물어 `--period`로 넘긴다. 기간 없이 실행하면 기간 검사를 건너뛰고, `08-02`·`9/5`처럼 연도 없는 날짜는 해석할 수 없어 보류된다.
- 스크립트가 출력하는 JSON 요약(확정 건수, 합계, 제외·보류 목록, 경고)을 결과 보고에 쓴다.
- 한글 파일명은 macOS에서 자모가 분리돼(NFD) 저장되는 일이 있다. 경로를 손으로 타이핑하지 말고 폴더 목록에서 찾은 실제 경로를 넘긴다.

Python을 실행할 수 없는 환경이면 아래 규칙을 그대로 따라 직접 같은 시트 3개를 만든다. 스크립트는 이 규칙을 코드로 옮긴 것일 뿐이다.

### 3. 규칙 확인 후 결과를 보고한다
스크립트를 돌린 뒤 JSON 요약을 메모 시트의 기준과 다시 맞춰 본다. 다르면 사용자에게 알리고, 고칠 방법을 제안한다.

## 정리 규칙과 그 이유

**값 변환** — 합계를 내려면 숫자여야 한다.
- 날짜: `2026.08.01`, `2026/08/01`, `08-02`, `8월 2일`, 엑셀 날짜값을 모두 날짜로 바꾼다. 연도가 없으면 보고기간의 연도를 쓴다.
- 금액·건수: `349,300원`, `₩111,100`, ` 178,200 `, `30건`, 글자로 된 `'175'`에서 원·₩·건·쉼표·공백을 빼고 숫자로 바꾼다.
- 기록 ID·지역 등 앞뒤 공백을 지운다. 마감여부 `Y`는 `확정`으로 통일한다.

**표기 통일은 띄어쓰기만 다른 경우에만** 한다. `현장 상담`/`현장상담`, `인터넷+Btv`/`인터넷+B tv`처럼 공백을 빼면 같아지는 표기는 더 많이 쓰인 쪽으로 맞춘다. `고객안내`와 `기존고객안내`, `온라인안내`와 `온라인 광고`, `수도권`과 `서울·경기`는 **뜻이 다를 수 있으니 합치지 않는다.** 합치면 활동별·지역별 실적이 조용히 틀어진다. 합치고 싶다면 사용자에게 묻는다.

**데이터가 아닌 줄은 삭제** — 빈 줄, 중간에 반복된 머리글, `담당자 임시 합계` 같은 합계·소계 줄. 원본 임시 합계는 글자 금액을 빼고 더하거나 중복 행을 더해서 틀리는 경우가 많다. 검증 시트에 원본 수식과 차이를 적어 둔다.

**제외 (규칙에 따라 뺌)**
- 같은 기록 ID가 여러 번 있으면 **수정차수가 가장 높은 것**만 쓴다. 담당자가 고쳐 보낸 값이 최신이기 때문이다.
- 같은 차수인데 **숫자(날짜·금액·건수)가 모두 같으면** 단순 중복이다. 먼저 나온 행을 남기고 나머지를 뺀다. 지역·활동 표기만 다른 것은 사유에 적는다.
- 집행일이 **보고기간 밖**이거나 마감여부가 **잠정**(N·미확정 포함)이면 뺀다.

**보류 (담당자 확인 전까지 합계에서 뺌)** — 추측으로 숫자를 만들지 않기 위해서다.
- 금액이 비어 있는 기록은 **0원으로 채우지 않는다.** 0원과 '모름'은 다르다.
- 같은 차수인데 숫자가 서로 다른 기록은 어느 쪽이 맞는지 알 수 없으니 모두 보류한다.
- 날짜·숫자를 해석할 수 없거나, 마감여부 값이 불분명해도 보류한다.

**확정에 넣되 표시만** — 취소가 접수보다 많거나, 처리완료가 접수보다 많거나, 금액이 음수인 기록은 원본 값 그대로 넣는다. 검토 메모와 검증 시트에 "확인 권장"으로 적는다. 데이터를 고칠 근거가 없기 때문이다.

## 검증 시트에 넣는 항목

- 확정 + 제외 + 보류 = 원본 기록 수 (한 건도 사라지거나 두 번 세지 않았는지)
- 원본 데이터 영역의 모든 행이 확정·제외·보류·삭제 중 하나로 분류됐는지
- 확정 건수, 기록 ID 중복 없음
- 금액·상담·접수·취소·처리완료 합계: 기대값은 원본 셀을 다시 읽어 계산한 값, 실제값은 확정실적 시트의 SUM 수식
- 금액·건수 칸이 모두 숫자인지, 마감여부가 모두 확정인지, 집행일이 모두 보고기간 안인지
- 알아둘 점: 원본 임시 합계와 차이, 값 이상 기록, 보류 기록, 표기 통일 기준

수식 결과는 엑셀에서 파일을 열어야 계산된다. 엑셀로 열어 확인하지 못했다면 결과 보고에서 그렇게 말한다.

## 결과 보고 형식

사용자에게는 짧은 존댓말로, 결론부터 말한다.

1. 결과 파일 경로
2. 확정 건수와 합계. **원본 기록 수도 함께 적는다.** 예: "원본 101건 중 확정 90건, 사용금액 17,766,900원"
3. 원본 기록이 어떻게 나뉘었는지: 확정 / 제외(사유별 건수) / 보류(기록 ID와 사유)
4. 담당자에게 확인할 것: 보류 기록, 확인 권장 기록
5. 검증 결과: 통과한 항목 수, 확인하지 못한 것

원본 파일을 바꾸지 않았다는 것과, 합치지 않고 그대로 둔 표기가 무엇인지도 한 줄씩 알린다.
